# 方法论与阈值档案

「年度新高 + 平滑爬升」策略的完整规则说明。核心思想：**用工程化指标复刻缠论「窄中枢 + 第三类买点」**——在贴近一年新高的位置，找低波动、结构收敛、流动性充足的票，等突破确认。

## 策略画像

选的是这样的股票：价格在一年高位附近（距 250 日最高收盘 ≤15.5%），近 30 日在一个窄幅区间里平滑震荡爬升（箱宽 ≤20%），每天波动节奏均匀（振幅 CV ≤0.47），没有连续单边（≤6 天），没有爆拉爆砸，成交活跃但不过热（日均 >4 亿、换手 <6%）。

与缠论的对应关系：

| 缠论 | 本策略实现 |
|---|---|
| 三个连续次级别走势的重叠构成中枢 | zigzag 转折点（1.5% prominence）+ 起伏次数 |
| 中枢有明确 ZG/ZD 边界 | 30 日箱宽 ≤20%（外包络口径） |
| 上涨 = 中枢依次抬高 | 高低点同步抬升检查 |
| 第三类买点（离开中枢回抽不回） | 突破 30 日最高收盘 ×1.05 触发买入 |
| 跌回中枢破坏结构 | 从 30 日高点回撤 −20% 移除 |

## 阈值档案（能否改动看这里）

### 回测校准过（2026-10-23，yh_screen，2023-01~2026-10，79.3 万样本，持有 20 日）

| 参数 | 值 | 依据 |
|---|---|---|
| PROX_NOW_GATE | 0.845 | 现价/250日最高收盘。回测四档：0.90/箱25 胜率46.6% → 0.90/箱20 胜率50.7% → 0.90/箱15 胜率53.5% → 0.95/箱15 胜率58.7%。0.845 是「85%档」意图的浮点安全写法 |
| BOX_WIDTH_GATE | 0.20 | 30日箱宽（收盘外包络）。同上回测的胜率/候选密度平衡点 |
| MIN_LIST_DAYS | 120 | 次新股没有可信的 250 日年高 |
| MIN_BARS_250 | 200 | 排除长期停牌 |

### 硬指标（使用者纪律，不可放宽）

| 参数 | 值 | 理由 |
|---|---|---|
| 30日日均成交额 | > 4 亿 | 流动性安全垫。2026-10-29 修正：必须用 30 日均口径，当日口径会误杀缩量慢牛股 |
| 近30日平均换手率 | < 6% | 换手率过高=资金脉冲票，与「安静爬升」画像互斥。⚠️ NLP 措辞必须写「近30日平均换手率」——「30日日均换手率」会导致 tdx_screener 解析失败（2026-10-30 实测） |

### 行业剔除（2026-11-03 起生效）

`daily_tdx.py` 的 `EXCLUDE_BANKS = True`：候选池入口整批剔除**银行**（证监会 J66 货币金融服务，45 只）。
依据：银行形态普遍极平（大量 Q 级静默）占用池名额、与进攻定位不符；独立回测（参数决策说明书 v2，150 万事件）亦列银行为负 alpha 行业。
数据源：`out/fundamental_cache.parquet`（baostock 证监会分类）；缓存缺失时退化为名称含「银行」兜底。要恢复纳入银行，把开关改为 False 即可。

### 初筛粗筛口径（2026-11-03 修正）

`SCREENER_QUERY` 的位置条件是 **80%**（粗筛），不是 84.5%——因为 tdx_screener 的「250日最高价」是**日内最高价**口径，比引擎 `PROX_NOW_GATE=0.845` 的**收盘口径**更严，等值使用会在门口误杀「收盘已回年高附近但年内有长上影」的票（实测挡掉 21 只含牧原/迈瑞/顺丰）。初筛宁宽，精确拦截全部交给引擎。

### 形态层工程参数（可调，但改动需自担风险）

- `SWING_PROMINENCE_PCT = 0.015`：转折点显著度（相对均价 1.5%）
- `MAX_AMPLITUDE_RATIO_TO_SECOND = 1.5` / `TO_AVG = 1.8`：段振幅均匀性
- `MAX_AMPLITUDE_CV = 0.47`、平均段振幅 4%~35%
- `MAX_CONSECUTIVE_UP/DOWN_DAYS = 6`
- `MAX_50D_DECLINE_PCT = -0.06`（实际用于 30 日）、`MAX_50D_RISE_PCT = 0.35`、`MAX_10D_DECLINE_PCT = -0.05`
- `EXTREME_SHARPNESS = 5.0`（极端尖锐转折剔除）、`EXTREME_V_CHANGE_PCT = 0.12`（深V）

### 影子指标（只输出不拦截，转正前必须回测）

2026-10-29 新增，目标是解决外包络箱宽的「历史包袱」问题（一个月前剧震过的票被误杀）：

| 指标 | 观察阈值 | 定义 |
|---|---|---|
| 缠论中枢宽度 | ≤10% | 最近 3 段的重叠区 (min(段高)−max(段低))/max(段低)，单日 57 只样本观察值 |
| 振幅 v2（方向敏感） | — | 爆拉悬空（单段>+15%且现价仍高出段起点8%）拒；深跌未修复（单段>−15%且修复度<50%）拒 |

开关在 `jianchashuju_local.py` 的 `PatternRules`：`CENTRAL_ZONE_ENABLED`（默认 False）、`ABNORMAL_AMP_MODE`（默认 'v1'）。

### 已转正：中枢偏离度闸（2026-11-03 起生效，用户拍板）

`DEV_FROM_ZG_ENABLED = True`、`DEV_FROM_ZG_GATE = 0.08`：**现价高出中枢上沿 ZG 超过 +8% 直接剔除**（延伸段不追）。
起源：中远海控 601919 突破中枢后偏离 +9.2%，用户确认此类票不入选。
依据：健康三买区在 ZG ±3% 内；爆拉/延伸票 ≥+10%（新产业、海正药业实测）。
豁免：算不出中枢（转折点 <4 或三段无重叠）时跳过本闸——Q 级静默慢爬票不受影响。

### 静默票规则（2026-10-29 起生效）

30 日内识别不出转折点的票（`ALLOW_QUIET_PASS=True`）不再淘汰，打 Q 级、固定形态分 70 放行——这类票往往是极度平滑的慢爬大盘票（水电/核电/消费权重；银行自 2026-11-03 起整批剔除），正是策略核心画像。后续所有闸门（位置、箱宽、成交）照常执行。

已知现象：Q 级身份可能隔日翻转（某天一根阳线让 zigzag 突然识别不出转折），形态分 95↔70 跳变会影响综合排名稳定性，后续可能做衰减平滑。

## 公司质地层（company_analysis.py）

baostock 免费财务数据，四维打分：盈利能力（ROE 杜邦）/ 成长（营收净利同比）/ 现金流质量 / 估值（PE/PB/股息率）。银行与非银行分口径。综合分 = 形态 × 40% + 质地 × 60%。

## 常见淘汰原因对照

| 明细表里的淘汰原因 | 含义 |
|---|---|
| 未检测到波动 | （已废弃）现改为 Q 级静默放行 |
| 异常大振幅: 最大是次大X倍 | 有一段起伏明显深于其他段（剧震事件） |
| 连续趋势: 连续N日涨/跌>允许6日 | 单边行情，不是震荡爬升 |
| 30日箱宽X%>20% | 区间振幅过大 |
| 现价/年高0.XX<0.845 | 距年高太远（左侧票） |
| 成交X亿<4亿 | 30 日均成交不足 |
| 30日高<250日高×90% | 近一个月没摸到过年高附近 |
